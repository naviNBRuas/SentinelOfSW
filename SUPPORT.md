# Support

## Getting help

- **Usage questions** — check the [README](README.md) first (installation,
  quick start, all CLI flags, mode reference), then `docs/MODULES.md` for
  per-module detail and `docs/CONFIGURATION.md` for `settings.toml`.
- **Bug reports** — open a
  [GitHub Issue](https://github.com/naviNBRuas/SentinelOfSW/issues) with
  your OS, Rust version, the command you ran, and the actual vs. expected
  output. Redact any real target IPs/hostnames from engagements you're not
  authorized to disclose.
- **Feature requests / ideas** — open a GitHub Issue, or start a
  [Discussion](https://github.com/naviNBRuas/SentinelOfSW/discussions) if
  one is enabled on the repo.
- **Security vulnerabilities** — do **not** open a public issue. See
  [SECURITY.md](SECURITY.md).

## Response times

Sentinel is maintained by one person in their spare time — see
[GOVERNANCE.md](GOVERNANCE.md). There's no SLA; issues and PRs are
triaged as time allows.

## Before you ask

- Search existing [issues](https://github.com/naviNBRuas/SentinelOfSW/issues)
  first — your question may already be answered.
- Include enough detail to reproduce: target type (IP/domain/CIDR), mode
  flags used, and whether `--docker` or `--vpn` were involved.
